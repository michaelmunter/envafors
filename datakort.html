02 · Funktion

Fra CVR til kildesvar

fetch(cvr) kalder Labs og kontrollerer HTTP 200, gyldig JSON og kendt svarstruktur. Først derefter erstattes det senest gemte svar. Indekset får URL, hentetid og SHA-256.

03 · Data

Det gemte kildesvar

Én uændret JSON-fil pr. CVR. Det fælles indeks fortæller, hvor og hvornår svaret er hentet, og indeholder hashværdien, som bruges til at kontrollere filens bytes.

04 · Funktion

Fra JSON til rækker

load_sources() afstemmer CVR med filnavn og kilde-URL og kontrollerer hash og svarstruktur. normalize() laver én række pr. kildeobjekt, bevarer de to ejerandele separat og markerer konkrete afvigelser. transform() samler rækker og fund på tværs af CVR-numre.
